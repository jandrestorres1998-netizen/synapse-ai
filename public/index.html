🔌 Conexión Plug-and-Play en 1 Línea

SynapseAI es 100% compatible con el SDK oficial de OpenAI, LangChain, Cursor, agentes autónomos y cualquier software existente.

🐍 Conexión en Python (OpenAI SDK)

PYTHON 
from openai import OpenAI

# Solo cambia el baseURL hacia SynapseAI Gateway
client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="synapse_enterprise_key"
)

response = client.chat.completions.create(
    model="auto-synapse", # Enrutamiento dinámico automático
    messages=[{"role": "user", "content": "Analiza este reporte..."}]
)
print(response.choices[0].message.content)

🌐 Conexión en Node.js / TypeScript

TYPESCRIPT 
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:3000/v1',
  apiKey: 'synapse_enterprise_key'
});

const res = await openai.chat.completions.create({
  model: 'auto-synapse',
  messages: [{ role: 'user', content: 'Genera el contrato...' }]
});
console.log(res.choices[0].message.content);
