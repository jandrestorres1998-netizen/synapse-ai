Referencia de la API

Rutas estándar /v1 compatibles con el formato de OpenAI para conectar sus aplicaciones modificando únicamente la URL base, y rutas /api de control interno.

Versión estable v2.0.0 · Especificación REST / JSON

Autenticación y encabezados HTTP

Todas las solicitudes dirigidas a la API requieren autenticación mediante un encabezado HTTP estándar. Puede utilizar cualquiera de estos formatos:

Authorization: Bearer <su_llave_api>
# o alternativamente:
x-api-key: <su_llave_api>

Para aplicaciones que consumen inferencia de IA, utilice una clave con el prefijo de ámbito inference: (definido en su archivo .env). De este modo, la clave queda restringida al envío de prompts y no podrá acceder al panel de administración ni a la bóveda.

1 · Rutas /v1 (Compatibles con OpenAI)

Estas rutas se adhieren al estándar de OpenAI. Cualquier biblioteca, cliente SDK (Python, Node.js, Go) o framework de orquestación (LangChain, LlamaIndex) puede utilizar SynapseAI cambiando la dirección base (baseURL).

POST /v1/chat/completions

Procesa una solicitud conversacional, inspecciona el texto en tiempo real para anonimizar datos confidenciales (IDs, cuentas bancarias, tarjetas, llaves secretas), reenvía el contenido higienizado al proveedor de IA configurado, sella la transacción en el libro de auditoría SHA-256 y devuelve la respuesta.

Ejemplo mediante cURL:

curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer inference:llave_secreta_empresa" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "user", "content": "Analiza la declaración de impuestos del cliente con ID 12345678Z"}
    ],
    "temperature": 0.2
  }'

Integración en Python (SDK Oficial de OpenAI):

from openai import OpenAI

# Modifique únicamente base_url para apuntar a su pasarela SynapseAI:
client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="inference:llave_secreta_empresa"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "Redacta un acuerdo de confidencialidad estándar"}
    ]
)

print(response.choices[0].message.content)
GET /v1/models

Retorna la lista de modelos de Inteligencia Artificial disponibles según los proveedores activos en el sistema (OpenAI, Anthropic, Google o modelos locales en Ollama).

2 · Rutas /api (Control, Auditoría y Extensión)

Endpoints para la administración del sistema, telemetría local y comunicación con la extensión de navegador:

GET /api/gateway/stats

Proporciona métricas consolidadas: solicitudes procesadas, consumo acumulado de tokens y volumen de datos confidenciales anonimizados. Requiere clave de operador (ámbito completo).

POST /api/extension/event

Recepción de eventos preventivos reportados por la extensión de navegador. Admite claves con ámbito report:. Registra la regla activada (ej. es_dni) y la acción tomada; nunca el texto en bruto.

GET /api/vault/status

Verifica el estado de la bóveda criptográfica AES-256-GCM. Certifica si la llave maestra SYNAPSE_VAULT_KEY está cargada correctamente o si el sistema requiere configuración.

GET /api/security/audit/export

Exporta el libro de auditoría en formato estructurado (CSV/JSON) para revisiones de cumplimiento normativo y peritajes de seguridad.

Códigos de Respuesta HTTP

Código Significado Causa habitual
200 OK Solicitud exitosa La solicitud fue inspeccionada y la respuesta del modelo fue entregada.
400 Bad Request Solicitud inválida o bloqueada Formato JSON inválido o solicitud rechazada preventivamente por directiva SYNAPSE_DLP_ON_DETECTION=block.
401 Unauthorized Autenticación requerida Falta el encabezado Authorization o la clave no coincide con ninguna de las llaves configuradas.
403 Forbidden Permisos insuficientes El ámbito de la clave no autoriza la acción (ej. utilizar una clave report: en /v1/chat/completions).
429 Too Many Requests Límite de tasa o cuota superada Se superó el límite de peticiones por minuto o el presupuesto asignado en SYNAPSE_BUDGET_DAILY_USD.
503 Service Unavailable Proveedor no disponible El servicio de IA externo presenta una interrupción o no responde dentro del tiempo límite establecido.
Compatibilidad Funcional: La pasarela cubre todas las funciones de inferencia de texto conversacional (chat completions) y catálogo de modelos. Para cargas multimodales o flujos de entrenamiento especializados, consulte con el soporte técnico de despliegue.
