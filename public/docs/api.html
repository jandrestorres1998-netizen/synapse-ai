Referencia de la API

Rutas /v1 compatibles con el formato de OpenAI para conectar sus programas cambiando solo una línea, y rutas /api de control interno.

Última revisión: Septiembre de 2026 · Versión 2.0.0

Cómo autenticarse

Todas las llamadas a la API requieren autenticación mediante una cabecera HTTP estándar. Puedes utilizar cualquiera de estos dos formatos:

Authorization: Bearer <tu_clave>
# o alternativamente:
x-api-key: <tu_clave>

Para conectar programas que realizan consultas de IA, utiliza siempre una clave con el prefijo de ámbito inference: (definida en su archivo .env). Así, esa clave solo podrá enviar preguntas a los modelos y no tendrá permiso para alterar la configuración del servidor.

1 · Rutas /v1 (Compatibles con OpenAI)

Estas rutas siguen la especificación pública de OpenAI. Cualquier programa, script o biblioteca (LangChain, LlamaIndex, SDK oficial de OpenAI) puede utilizar SynapseAI cambiando únicamente la dirección base (baseURL).

POST /v1/chat/completions

Recibe una consulta, analiza el texto en vuelo para borrar DNI, cuentas bancarias, tarjetas o claves, envía el texto limpio al proveedor de IA configurado, registra la operación en el registro inmutable y devuelve la respuesta.

Ejemplo con cURL:

curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer inference:clave_secreta_empresa" \
  -d '{
    "model": "gpt-4o",
    "messages": [
      {"role": "user", "content": "Calcula el IRPF del empleado con DNI 12345678Z"}
    ],
    "temperature": 0.2
  }'

Integración en Python con el SDK de OpenAI:

from openai import OpenAI

# Solo cambia la línea base_url apuntando a su servidor local:
client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="inference:clave_secreta_empresa"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {"role": "user", "content": "Redacta una cláusula de confidencialidad"}
    ]
)

print(response.choices[0].message.content)
GET /v1/models

Devuelve la lista de modelos de lenguaje disponibles en el servidor según los proveedores configurados en .env o en el almacén de credenciales.

2 · Rutas /api (Control y administración)

Rutas exclusivas para la gestión interna del programa, la extensión del navegador y la inspección de auditoría:

GET /api/gateway/stats

Devuelve contadores de actividad agregados: número de peticiones totales, volumen de tokens procesados y cuántos datos personales han sido redactados. Requiere clave de operador (ámbito completo).

POST /api/extension/event

Punto de recepción de alertas cuando un usuario confirma una intercepción en la extensión del navegador. Admite claves con ámbito report:. Solo recibe el identificador de la regla (ej. es_dni) y la acción; nunca el texto real.

GET /api/vault/status

Informa sobre el estado del cifrado en reposo del almacén de contraseñas. Confirma si la clave maestra SYNAPSE_VAULT_KEY está cargada correctamente o si el almacén opera en modo degradado.

GET /api/security/audit/export

Exporta el registro completo de peticiones en formato CSV para revisiones de cumplimiento normativo o auditorías de protección de datos.

Códigos de respuesta HTTP

Código Significado Causa habitual
200 OK Petición completada El texto ha sido revisado y la IA ha devuelto la respuesta.
400 Bad Request Petición incorrecta Formato JSON inválido o consulta rechazada porque SYNAPSE_DLP_ON_DETECTION=block.
401 Unauthorized Autenticación requerida Falta la cabecera Authorization o la clave no coincide con ninguna de SYNAPSE_API_KEYS.
403 Forbidden Ámbito insuficiente La clave enviada no tiene permisos para esa ruta (por ejemplo, usar una clave report: en /v1/chat/completions).
429 Too Many Requests Límite excedido Se ha superado el tope de peticiones por minuto o el presupuesto diario en SYNAPSE_BUDGET_DAILY_USD.
503 Service Unavailable Proveedor no disponible El proveedor de IA configurado no responde o no se han introducido credenciales válidas.
Hasta aquí llega: La compatibilidad con OpenAI cubre las funciones de chat y listado de modelos. No incluye herramientas propietarias en la nube de OpenAI como fine-tuning en remoto, generación de imágenes con DALL-E ni la API de asistentes con archivos adjuntos pesados.
