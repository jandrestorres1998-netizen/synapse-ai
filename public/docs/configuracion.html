Configuración del Sistema

Diccionario y especificación de todas las variables de entorno definidas en .env.example. Ámbitos de seguridad, cifrado en reposo, proveedores y control presupuestario en USD.

Versión estable v2.0.0 · Gestión por Entorno

El archivo de entorno (.env)

Toda la configuración del sistema se gobierna mediante el archivo .env en la raíz del proyecto. Este archivo contiene secretos criptográficos y credenciales maestras, por lo que está incluido en .gitignore y jamás debe publicarse en repositorios públicos.

Para iniciar la configuración, copie la plantilla base:

cp .env.example .env

1 · Servidor y Conectividad

Variable Valor por defecto Descripción
PORT 3000 Puerto TCP donde la pasarela escucha solicitudes HTTP.
HOST 127.0.0.1 Dirección IP de enlace. 127.0.0.1 restringe el tráfico a la máquina local; use 0.0.0.0 para recibir solicitudes desde la red interna de su empresa o contenedor Docker.
NODE_ENV development Entorno de ejecución (production o development). En producción se activan cabeceras de seguridad estrictas y validaciones adicionales.
LOG_LEVEL info Nivel de detalle de eventos en consola (debug, info, warn, error).

2 · Autenticación y Ámbitos de Claves

SynapseAI implementa un modelo de privilegios mínimos por ámbito para mitigar riesgos en caso de que una clave de cliente se vea comprometida:

Formato de la llave Ámbito concedido Uso recomendado
clave_secreta Ámbito completo (Operador) Acceso total: consola de gestión, configuración, bóveda de claves y exportación de auditoría. Exclusivo para administradores de TI.
inference:clave_secreta Solo inferencia Autoriza exclusivamente el envío de prompts mediante /v1/*. No puede consultar claves ni registros de auditoría.
report:clave_secreta Solo reporte de extensión Autoriza exclusivamente la notificación de eventos preventivos desde el navegador mediante /api/extension/event.

Regla de seguridad: Asigne a las extensiones de los colaboradores únicamente claves con prefijo report:. De esta manera, el navegador no almacena secretos que puedan acceder a la bóveda o al libro de auditoría.

Variable Valor por defecto Descripción
SYNAPSE_API_KEYS (vacío) Lista de claves de acceso separadas por comas. Permite rotación de credenciales en caliente sin interrumpir la operación.
SYNAPSE_DISABLE_AUTH false Deshabilita la validación de claves. Solo permitido en pruebas locales de desarrollo; el servidor rechaza iniciar si se combina con NODE_ENV=production.
SYNAPSE_CORS_ORIGINS localhost:3000 Orígenes autorizados para solicitudes CORS desde navegadores web. Evite comodines globales (*) en producción.
SYNAPSE_TRUST_PROXY_HOPS 0 Número de proxies inversos intermedios de confianza (Nginx, Caddy). 0 ignora X-Forwarded-For para prevenir suplantación de IP.

3 · Cifrado en Reposo y Auditoría

Variable Requisito Descripción
SYNAPSE_VAULT_KEY Mínimo 32 caracteres (256 bits) Llave maestra que cifra en reposo (AES-256-GCM) las credenciales de OpenAI, Anthropic y Google en el disco.
SYNAPSE_AUDIT_HMAC_KEY Cadena criptográfica Llave para firmar criptográficamente cada registro de actividad SHA-256, garantizando la inmutabilidad de la cadena de auditoría.

4 · Proveedores de Inteligencia Artificial

Configure las credenciales maestras de los modelos en el entorno o adminístrelas de forma cifrada mediante el panel web:

Variable Valor por defecto Descripción
OPENAI_API_KEY (vacío) Llave de API de OpenAI (GPT-4o, GPT-4o-mini).
OPENAI_BASE_URL api.openai.com/v1 Endpoint oficial de OpenAI.
ANTHROPIC_API_KEY (vacío) Llave de API de Anthropic (Claude 3.5 Sonnet, Haiku).
GOOGLE_API_KEY (vacío) Llave de API de Google (Gemini 1.5 Pro, Flash).
OLLAMA_BASE_URL 127.0.0.1:11434 URL de Ollama para ejecutar modelos de código abierto en hardware propio, con soberanía y aislamiento absoluto de internet.
SYNAPSE_PROVIDER_TIMEOUT_MS 120000 Tiempo máximo de espera (en milisegundos) antes de abortar una llamada si el proveedor de IA no responde (120 segundos por defecto).

5 · Directivas de Prevención de Fuga de Datos (DLP)

Variable Valores Descripción
SYNAPSE_DLP_ON_DETECTION redact | block Acción ante detección de datos sensibles. redact (por defecto) sustituye el dato por una etiqueta segura y permite continuar la consulta; block rechaza la petición con código HTTP 400.
SYNAPSE_DLP_STORE_PLAINTEXT false | true Almacenamiento de texto en bruto en auditoría. Fijado en false: nunca se almacenan datos sin anonimizar para evitar brechas secundarias.

6 · Control de Costos y Presupuesto en USD ($)

Variable Valor por defecto Descripción
SYNAPSE_BUDGET_DAILY_USD 0 (sin límite) Límite diario de gasto en dólares (USD) por clave. El sistema reserva saldo preventivamente antes de cada llamada y bloquea consumos excedentes.
SYNAPSE_BUDGET_MONTHLY_USD 0 (sin límite) Límite mensual de gasto en dólares (USD) por clave.
SYNAPSE_BUDGET_DAILY_USD_GLOBAL 0 (sin límite) Límite diario consolidado en USD para todas las claves activas de la organización.

Generación de Llaves Seguras

Comando Criptográfico

Para generar llaves maestras de 32 bytes con entropía segura en Linux o macOS:

openssl rand -hex 32

En Windows con PowerShell:

-join ((1..64) | ForEach-Object { '{0:x}' -f (Get-Random -Max 16) })
Aplicación de Cambios: Al actualizar valores en el archivo .env, es necesario reiniciar el servicio o contenedor para cargar las nuevas variables criptográficas en memoria.
