Configuración del sistema

Diccionario y especificación de todas las variables de entorno definidas en .env.example. Ámbitos de seguridad, cifrado en reposo y proveedores.

Última revisión: Septiembre de 2026 · Versión 2.0.0

El archivo .env

Toda la configuración del programa se gestiona mediante un archivo de texto llamado .env situado en la carpeta raíz del proyecto. Este archivo contiene secretos y contraseñas de sus modelos, por lo que está incluido en .gitignore y nunca debe subirse a ningún repositorio público.

Para empezar, genera el archivo. No copies la plantilla a mano: deja vacías las tres claves que el programa exige en producción —la de acceso, la del almacén y la del registro— y el contenedor muere al arrancar.

node scripts/init_env.js

Genera esas tres, apaga el proveedor simulado, te enseña una sola vez la clave de acceso y se niega a pisar un .env que ya exista. El resto del archivo sale de la plantilla, con sus comentarios, para que rellenes a mano lo que es su.

1 · Servidor y red local

Variable Valor por defecto Descripción
PORT 3000 Puerto TCP donde el programa escucha peticiones HTTP.
HOST 127.0.0.1 Dirección IP de escucha. 127.0.0.1 solo acepta conexiones del propio equipo; cambia a 0.0.0.0 para dar servicio a la red local de la oficina.
NODE_ENV development Define el entorno de ejecución (production o development). En producción se activan restricciones estrictas de seguridad.
LOG_LEVEL info Detalle del registro en consola (debug, info, warn, error).

2 · Autenticación y ámbitos de claves

SynapseAI utiliza un sistema de claves con ámbitos de privilegio estricto para que una clave comprometida no otorgue acceso al sistema completo:

Formato del secreto Ámbito concedido Uso recomendado
clave_secreta Ámbito completo (Operador) Acceso a todo: panel, configuración, vault de claves y auditoría. Solo para el responsable de sistemas.
inference:clave_secreta Solo inferencia Permite únicamente enviar preguntas a la IA por /v1/*. No puede leer claves ni ver auditorías.
report:clave_secreta Solo reporte de extensión Permite únicamente notificar incidencias desde la extensión por /api/extension/event.

Regla de seguridad esencial: Entrega a la extensión del navegador de los empleados únicamente una clave con prefijo report:. Sin ámbitos, la clave guardada en el navegador del empleado podría usarse para descifrar las claves de los modelos o descargar el historial de auditoría del despacho.

Variable Valor por defecto Descripción
SYNAPSE_API_KEYS (vacío) Lista de claves de acceso separadas por comas. Permite rotar credenciales sin interrumpir el servicio.
SYNAPSE_DISABLE_AUTH false Desactiva la comprobación de claves. Solo permitido para pruebas en desarrollo; el servidor rechaza arrancar si se combina con NODE_ENV=production.
SYNAPSE_CORS_ORIGINS localhost:3000 Lista de orígenes web autorizados para consultar la API desde navegadores. Nunca pongas comodines (*).
SYNAPSE_TRUST_PROXY_HOPS 0 Número de proxies inversos de confianza (Nginx, Caddy) situados delante. 0 ignora la cabecera X-Forwarded-For para evitar suplantaciones de IP.

3 · Cifrado en reposo (Vault y Auditoría)

Variable Requisito Descripción
SYNAPSE_VAULT_KEY Mínimo 32 caracteres Clave maestra que cifra en reposo las credenciales de OpenAI, Anthropic y Google guardadas en el disco del servidor. Sin ella, el sistema cae a un modo local inseguro.
SYNAPSE_AUDIT_HMAC_KEY Cadena criptográfica Clave secreta para firmar matemáticamente cada bloque del registro de actividad. Impide que nadie pueda retocar el registro de peticiones sin que se rompa la cadena.

4 · Proveedores de IA

Puedes configurar aquí las claves de acceso de los modelos o introducirlas cifradas a través del panel visual:

Variable Valor por defecto Descripción
OPENAI_API_KEY (vacío) Clave de API de OpenAI (ChatGPT, GPT-4o).
OPENAI_BASE_URL api.openai.com/v1 Dirección del servicio de OpenAI.
ANTHROPIC_API_KEY (vacío) Clave de API de Anthropic (Claude 3.5 Sonnet).
GOOGLE_API_KEY (vacío) Clave de API de Google (Gemini 1.5 Pro/Flash).
OLLAMA_BASE_URL 127.0.0.1:11434 Dirección de Ollama si ejecutan modelos de IA en local en su propio hardware, sin conexión a internet.
SYNAPSE_PROVIDER_TIMEOUT_MS 120000 Tiempo máximo de espera (en milisegundos) antes de abortar una petición a un proveedor si no responde (2 minutos por defecto).

5 · Reglas de borrado de datos (DLP)

Variable Valores Descripción
SYNAPSE_DLP_ON_DETECTION redact | block Acción cuando se detecta un dato confidencial. redact (por defecto) sustituye el dato por una etiqueta inocua y deja continuar la consulta; block rechaza la petición con código 400.
SYNAPSE_DLP_STORE_PLAINTEXT false | true Guardar el texto sin redactar en el registro de auditoría. Fijado en false: almacenar los datos que intentas proteger multiplica el riesgo de fuga.

6 · Control de gasto y presupuesto

Variable Valor por defecto Descripción
SYNAPSE_BUDGET_DAILY_USD 0 (sin límite) Tope diario de gasto en dólares por cliente o clave. Antes de enviar cada petición, el programa reserva el coste del peor caso y frena el consumo si se supera el tope.
SYNAPSE_BUDGET_MONTHLY_USD 0 (sin límite) Tope mensual de gasto por clave.
SYNAPSE_BUDGET_DAILY_USD_GLOBAL 0 (sin límite) Tope diario acumulado de todas las claves combinadas en su empresa.

Para tu equipo técnico

Generación de claves criptográficas seguras

Para generar contraseñas y claves de 32 bytes con entropía real en Linux o macOS:

openssl rand -hex 32

En Windows con PowerShell:

-join ((1..64) | ForEach-Object { '{0:x}' -f (Get-Random -Max 16) })
Hasta aquí llega: Modificar los valores del archivo .env requiere reiniciar el proceso del programa para que la nueva configuración entre en vigor. Los cambios no se aplican en caliente por motivos de seguridad criptográfica.
