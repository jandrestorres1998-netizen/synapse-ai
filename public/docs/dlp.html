Catálogo de Protección de Datos (DLP)

Especificación técnica de todos los identificadores personales, documentos fiscales y credenciales que SynapseAI reconoce, valida matemáticamente y anonimiza antes del envío a la IA.

Versión estable v2.0.0 · Validación Matemática Determinista

Metodología de Inspección y Validación

El motor DLP de SynapseAI opera mediante una arquitectura de dos etapas continuas:

  1. Identificación de patrón sintáctico: Detecta secuencias numéricas o alfanuméricas coincidentes con las estructuras formales de documentos y credenciales.
  2. Comprobación matemática determinista: Aplica las fórmulas de validación oficiales (módulo 23 para documentos de identidad, módulo 97 para cuentas bancarias internacionales o algoritmo de Luhn para tarjetas). Si la cifra de control no es válida, no se altera el texto, evitando falsos positivos con cantidades numéricas ordinarias o códigos de factura.

1 · Identificaciones Personales y Tributarias

Identificador Fórmula de comprobación Etiqueta sustituta Severidad
DNI / ID Personal Módulo 23: el número se divide entre 23 y el residuo determina la letra oficial en la tabla TRWAGMYFPDXBNJZSQVHLCKE. [REDACTED_ES_DNI_NIE] CRITICAL
NIE (Residentes) Prefijos alfanuméricos transformados a valores numéricos con cálculo de módulo 23 idéntico. [REDACTED_ES_DNI_NIE] CRITICAL
CIF / Identificación Fiscal Corporativa Letra inicial de tipo societario + suma ponderada de posiciones pares e impares para verificar el dígito de control. [REDACTED_ES_CIF] HIGH

2 · Cuentas Bancarias y Medios de Pago

Instrumento Fórmula de comprobación Etiqueta sustituta Severidad
IBAN / Cuentas Bancarias Internacionales Norma internacional ISO 7064 MOD-97-10. Reubicación de los caracteres de país y cálculo del residuo para validar cuentas bancarias internacionales. [REDACTED_IBAN] CRITICAL
Tarjetas de Crédito y Débito Algoritmo de Luhn (módulo 10 con duplicación alternada). Cobertura para Visa, Mastercard, American Express y emisores de 13 a 19 dígitos. [REDACTED_CREDIT_CARD] CRITICAL

3 · Identificadores Internacionales

País / Documento Estructura y validación Etiqueta sustituta Severidad
RFC (México) Registro Federal de Contribuyentes: estructura oficial de personas físicas y morales con homoclave. [REDACTED_MX_RFC] HIGH
CURP (México) Clave Única de Registro de Población: 18 caracteres alfanuméricos con estructura oficial RENAPO. [REDACTED_MX_CURP] CRITICAL
CPF (Brasil) Cadastro de Pessoas Físicas: 11 dígitos numéricos con comprobación de dos dígitos verificadores (módulo 11). [REDACTED_BR_CPF] CRITICAL
CNPJ (Brasil) Cadastro Nacional da Pessoa Jurídica: 14 dígitos con validación matemática para personas jurídicas. [REDACTED_BR_CNPJ] HIGH

4 · Claves Técnicas y Secretos de Infraestructura

Tipo de secreto Patrón reconocido Etiqueta sustituta
Llaves de API OpenAI Cadenas con prefijo oficial sk- de longitud variable. [REDACTED_OPENAI_KEY]
Credenciales AWS Identificadores de acceso AKIA... y llaves secretas de Amazon Web Services. [REDACTED_AWS_SECRET]
Tokens de GitHub Tokens de acceso con prefijos oficiales ghp_, gho_ o ghs_. [REDACTED_GITHUB_TOKEN]
JSON Web Tokens (JWT) Estructura de tres bloques Base64URL con firma criptográfica válida. [REDACTED_JWT]

Módulos del Sistema

Los algoritmos de validación residen en:

  • server/identity-checksums.js: validaciones matemáticas puras sin dependencias externas.
  • server/dlp-engine.js: motor de inspección en flujo, preservación de saltos de línea y anonimización reversible.

Para ejecutar la suite de pruebas unitarias sobre las reglas DLP:

npm test
Cobertura de Prevención: La pasarela higieniza el texto antes de transmitirlo al proveedor de IA. Para una protección integral de toda la estación de trabajo, combine la pasarela central con el despliegue de la extensión de navegador.
