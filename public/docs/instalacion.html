Guía de instalación

Los tres caminos para poner en marcha el programa en vuestra propia red: contenedor Docker, Node.js estándar o como servicio local en Windows.

Última revisión: Septiembre de 2026 · Versión 2.0.0

Requisitos mínimos

SynapseAI es un programa ligero desarrollado en JavaScript. No requiere tarjetas gráficas de cálculo (GPU) ni hardware especializado; la comprobación de identificadores corre íntegramente en el procesador convencional (CPU).

  • Procesador: 2 núcleos o superior.
  • Memoria RAM: 2 GB disponibles (el proceso consume habitualmente entre 90 y 180 MB).
  • Espacio en disco: 500 MB para el programa y sus dependencias, más el espacio destinado al registro de auditoría local.
  • Entorno: Docker 20.10+ o Node.js 18 LTS o superior.

Camino 1 · Docker (Recomendado)

Es la forma más rápida y limpia de instalar el programa en un servidor de oficina o centro de datos sin ensuciar el sistema anfitrión.

Para arrancarlo con un único comando:

docker run -d \
  --name synapseai \
  -p 3000:3000 \
  -v synapse_data:/data \
  --restart unless-stopped \
  synapseai/gateway:2.0.0

Si gestionáis vuestros servicios mediante Docker Compose, podéis incluir esta definición en vuestro docker-compose.yml:

version: '3.8'
services:
  synapseai:
    image: synapseai/gateway:2.0.0
    container_name: synapseai
    restart: unless-stopped
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
      - PORT=3000
      - HOST=0.0.0.0
      - SYNAPSE_VAULT_KEY=genera_una_clave_de_32_caracteres_minimo
    volumes:
      - ./data:/data
Hasta aquí llega: El contenedor expone el puerto 3000. Si queréis acceder desde fuera de la red local o usar conexiones seguras con certificado (HTTPS), vuestro equipo informático deberá colocar un proxy inverso (como Nginx o Caddy) delante del contenedor.

Camino 2 · Node.js y npm

Recomendado si deseáis auditar el código fuente, ejecutar pruebas en local o desplegarlo en un servidor Linux existente:

# 1. Descargar el código fuente
git clone https://github.com/synapse-ai/synapse-ai.git
cd SynapseAI

# 2. Instalar las dependencias oficiales
npm install --production

# 3. Crear el archivo de configuración
cp .env.example .env

# 4. Iniciar el programa
npm start

Para mantenerlo en ejecución continua en segundo plano, recomendamos utilizar un gestor de procesos estándar como systemd o pm2:

# Ejecución con PM2
pm2 start server/server.js --name synapseai
pm2 save
pm2 startup

Camino 3 · Windows (Servicio local)

Para despachos y asesorías que trabajan íntegramente sobre servidores Windows Server o puestos de trabajo con Windows 10/11:

  • Descarga e instala Node.js 18 o 20 LTS para Windows desde el instalador oficial .msi.
  • Descarga y descomprime el paquete de SynapseAI en una carpeta fija (por ejemplo, C:\SynapseAI).
  • Abre un terminal de PowerShell como Administrador y navega a la carpeta: 
    cd C:\SynapseAI
npm.cmd install --production
Copy-Item .env.example .env
  • Para arrancar manualmente: 
    npm.cmd start
  • Para que arranque automáticamente al encender el servidor sin necesidad de iniciar sesión, se puede utilizar el Programador de Tareas de Windows o una utilidad de servicios nativos como nssm (Non-Sucking Service Manager).

Comprueba que el programa responde

Una vez levantado el servidor, verifica que el sistema está operativo abriendo en tu navegador:

Comprobación rápida: Accede a http://localhost:3000/app para entrar al panel de administración.

También puedes solicitar el estado del almacén de claves por línea de comandos:

curl.exe http://localhost:3000/api/vault/status

Debe responder con un JSON indicando "status": "ready" o "initialized": true.

Para tu equipo técnico

Aislamiento de red y puertos

Por seguridad, la variable HOST en .env viene fijada por defecto en 127.0.0.1 para que el programa solo admita conexiones desde el propio equipo donde está instalado.

Si queréis que otros ordenadores de la oficina se conecten al programa:

# En vuestro archivo .env:
HOST=0.0.0.0
PORT=3000

Aseguraos de abrir el puerto TCP 3000 en el Firewall de Windows o en el cortafuegos de vuestro conmutador de red, y de definir claves con ámbito en SYNAPSE_API_KEYS.

Hasta aquí llega: El instalador no modifica vuestros registros del sistema operativo ni instala controladores ocultos. El programa corre como un proceso de usuario convencional y su ciclo de vida depende exclusivamente de vosotros.
