Guía de instalación

Los tres caminos para poner en marcha el programa en su propia red: contenedor Docker, Node.js estándar o como servicio local en Windows.

Última revisión: Septiembre de 2026 · Versión 2.0.0

Requisitos mínimos

SynapseAI es un programa ligero desarrollado en JavaScript. No requiere tarjetas gráficas de cálculo (GPU) ni hardware especializado; la comprobación de identificadores corre íntegramente en el procesador convencional (CPU).

  • Procesador: 2 núcleos o superior.
  • Memoria RAM: 2 GB disponibles (el proceso consume habitualmente entre 90 y 180 MB).
  • Espacio en disco: 500 MB para el programa y sus dependencias, más el espacio destinado al registro de auditoría local.
  • Entorno: Docker 20.10+ o Node.js 18 LTS o superior.

Camino 1 · Docker (Recomendado)

Es la forma más limpia de dejarlo corriendo en un servidor de oficina sin ensuciar el sistema anfitrión. La imagen se construye en su propia máquina, a partir del código que ustedes descargan: no se baja ningún programa ya compilado de internet, así que lo que acaba corriendo es exactamente lo que ustedes pueden leer antes de arrancarlo.

# 1. Descargar y descomprimir el paquete del servidor
#    (está en la página de Descargas, con su huella SHA-256)
unzip synapse-ai-servidor-v2.0.0.zip -d synapseai
cd synapseai

# 2. Generar la configuración (claves de acceso, almacén y registro)
node scripts/init_env.js

# 3. Construir y arrancar
docker compose up -d --build

# 4. Comprobar que responde
curl http://localhost:3000/healthz

El docker-compose.yml viene dentro del paquete y ya deja los datos fuera del contenedor. Si prefieren lanzarlo a mano, el equivalente es:

docker build -t synapseai:2.0.0 .

docker run -d   --name synapseai   -p 3000:3000   --env-file .env   -e HOST=0.0.0.0   -v "$(pwd)/data:/app/data"   --restart unless-stopped   synapseai:2.0.0

Dentro de Docker hace falta HOST=0.0.0.0.

El archivo de configuración trae HOST=127.0.0.1, que es lo correcto cuando el programa corre directamente en una máquina. Dentro de un contenedor significa escuchar solo en su propio bucle interno: el puerto queda publicado pero no lleva a ninguna parte, y como la comprobación de salud también mira ahí dentro, el contenedor se declara sano mientras nadie puede entrar. El docker-compose.yml ya lo pone; si lanzan el comando a mano, no lo olviden.

Cuidado con dónde se monta la carpeta de datos.

Tiene que ser /app/data, no /data. Ahí dentro viven el almacén de claves cifrado, el registro de auditoría y el control de gasto. Si se monta en el sitio equivocado el programa arranca igual, sin quejarse, pero esos archivos se quedan dentro del contenedor y desaparecen la próxima vez que lo recreéis.

Hasta aquí llega: El contenedor abre el puerto 3000 en la red local, que es de donde llegan las peticiones de sus programas. Para llegar desde fuera de la oficina, o para usar conexiones cifradas con certificado (HTTPS), su equipo informático deberá colocar delante un proxy inverso como Nginx o Caddy.

Camino 2 · Node.js y npm

Recomendado si desean auditar el código fuente, ejecutar pruebas en local o desplegarlo en un servidor Linux existente:

# 1a. Clonar el repositorio (si quieren seguir las actualizaciones)
git clone https://github.com/jandrestorres1998-netizen/synapse-ai.git
cd synapse-ai

# 1b. O descomprimir el paquete descargado, que lleva su huella SHA-256
unzip synapse-ai-servidor-v2.0.0.zip -d synapseai
cd synapseai

# 2. Instalar las dependencias oficiales
npm install --omit=dev

# 3. Generar la configuración
node scripts/init_env.js

# 4. Iniciar el programa
npm start

Para mantenerlo en ejecución continua en segundo plano, recomendamos utilizar un gestor de procesos estándar como systemd o pm2:

# Ejecución con PM2
pm2 start server/server.js --name synapseai
pm2 save
pm2 startup

Camino 3 · Windows (Instalador automático como servicio)

Para despachos, gestorías y oficinas que trabajan sobre Windows 10, Windows 11 o Windows Server y buscan una instalación rápida sin ventanas negras de comandos:

Instalación automática en un clic

Recomendado para Windows

El paquete incluye el script instalar_servicio_windows.bat, que realiza todo el proceso de forma automática:

  1. Comprueba o instala Node.js LTS mediante el gestor oficial de paquetes de Windows (winget).
  2. Instala los componentes del programa en segundo plano sin dependencias de desarrollo.
  3. Registra SynapseAI en el Inicio automático de Windows para que arranque solo al encender la computadora.
  4. Crea un acceso directo en tu Escritorio: «SynapseAI — Panel de Control».
  5. Arranca el programa en segundo plano de forma silenciosa (sin dejar abierta ninguna ventana negra de consola) y abre el panel en tu navegador.
Doble clic en: instalar_servicio_windows.bat

Para detener o gestionar el servicio en segundo plano cuando lo necesites, se incluye también el archivo detener_servicio_windows.bat.

Comprueba que el programa responde

Una vez levantado el servidor, verifica que el sistema está operativo abriendo en tu navegador:

Comprobación rápida: Accede a http://localhost:3000/app para entrar al panel de administración.

También puedes solicitar el estado del almacén de claves por línea de comandos:

curl.exe http://localhost:3000/api/vault/status

Debe responder con un JSON indicando "status": "ready" o "initialized": true.

Para tu equipo técnico

Aislamiento de red y puertos

Por seguridad, la variable HOST en .env viene fijada por defecto en 127.0.0.1 para que el programa solo admita conexiones desde el propio equipo donde está instalado.

Si quieren que otros computadoras de la oficina se conecten al programa:

# En su archivo .env:
HOST=0.0.0.0
PORT=3000

Aseguraos de abrir el puerto TCP 3000 en el Firewall de Windows o en el cortafuegos de su conmutador de red, y de definir claves con ámbito en SYNAPSE_API_KEYS.

Hasta aquí llega: El instalador no modifica sus registros del sistema operativo ni instala controladores ocultos. El programa corre como un proceso de usuario convencional y su ciclo de vida depende exclusivamente de ustedes.
