Puesta en Marcha Rápida

Inicio Inmediato en Servidor Local

SynapseAI está desarrollado en Node.js de alto rendimiento. Para levantar un entorno funcional en su servidor en dos minutos:

# 1. Clonar el repositorio oficial
git clone https://github.com/jandrestorres1998-netizen/synapse-ai.git
cd synapse-ai

# 2. Instalar dependencias del sistema
npm install --omit=dev

# 3. Inicializar entorno y levantar el servicio
node scripts/init_env.js
npm start

El servidor iniciará en http://127.0.0.1:3000. Verifique la disponibilidad abriendo http://127.0.0.1:3000/app en su navegador.

Soberanía y Control Absoluto: SynapseAI opera enteramente en su propia infraestructura. Ningún dato confidencial, clave criptográfica ni registro de auditoría se envía a la nube de SynapseAI ni a intermediarios externos.
