  • Auditoría adversaria: el informe de los cinco revisores independientes con los fallos encontrados y corregidos.

Para tu equipo técnico

Clonado y arranque directo

SynapseAI está desarrollado en Node.js estándar. Para poner en marcha una instancia local de prueba en menos de dos minutos:

# 1. Clonar el repositorio
git clone https://github.com/jandrestorres1998-netizen/synapse-ai.git
cd synapse-ai

# 2. Instalar dependencias del servidor
npm install

# 3. Generar la configuración e iniciar
node scripts/init_env.js
npm start

El servidor escuchará por defecto en http://127.0.0.1:3000. Puedes comprobar que responde abriendo http://127.0.0.1:3000/app en tu navegador.

Hasta aquí llega: Esta documentación describe el funcionamiento técnico del software que se ejecuta en su propia red. SynapseAI no es un servicio en la nube ni mantiene servidores remotos que procesen sus consultas; la instalación, copias de seguridad y mantenimiento del servidor corren a cargo de su equipo informático.
